Ambient Sound Files
===================
Place the following loopable mp3 sound files into this directory:
- `forest.mp3` - Relaxing birds & forest atmosphere
- `rain.mp3` - Gentle rain & thunder
- `ocean.mp3` - Calm ocean waves
- `wind.mp3` - Mountain wind breeze

Note: The app is equipped with graceful error handling: if an audio file is missing, the UI still simulates the session with full interactivity and displays a helpful notice.
